# apps/desktop

App de escritorio: Tauri (shell nativo, webview del sistema) + Next.js/React (UI). Captura de micrófono, reproducción de audio en streaming, UI de conversación, cliente WebSocket hacia `apps/orchestrator`.

Owner: `frontend-engineer`. Ver [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md) para el contrato del protocolo WS.
