# Dashboards

Cada dashboard futuro debe vivir en su propio subdirectorio para mantener aislados sus datos, componentes y estilos:

- `tasks/`: dashboard de tareas y Gantt.
- `finance/`: reservado para el futuro dashboard financiero.
- `learning/`: reservado para el futuro dashboard de aprendizaje.

Los dashboards se abren bajo demanda desde una tool del agente; no se cargan todos al iniciar la aplicación.
