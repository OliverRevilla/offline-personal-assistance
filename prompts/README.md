# prompts

Prompts versionados como datos, no como strings embebidos en el código:

- `system/` — system prompt del asistente.
- `tools/` — schemas JSON de las tools invocables por el LLM (`buscar_nota`, `crear_nota`, etc.).
- `personas/` — variantes de tono/persona, si se agregan más adelante.

Owner: `lead-ai-engineer`.
