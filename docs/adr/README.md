# Architecture Decision Records

Un ADR por decisión de arquitectura no trivial (cualquier cosa que cambie el flujo de `docs/ARCHITECTURE.md`, mueva carga entre CPU/GPU, o cambie un contrato entre servicios). Formato: `NNNN-titulo-corto.md` con Contexto / Opciones consideradas / Decisión / Consecuencias.

Owner: `software-architect`.
