# packages/shared-contracts

Schemas compartidos entre `apps/orchestrator` (Python/Pydantic) y `apps/desktop` (TypeScript): formato de mensajes de control WS, framing de audio, y schemas de tools invocables por el LLM. Fuente única de verdad para evitar que backend y frontend diverjan sobre el protocolo.

Owner: `integration-engineer` (coordina con `backend-engineer` y `frontend-engineer`).
